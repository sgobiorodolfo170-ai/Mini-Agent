## 2. 任务拆解

### M0 脚手架（约 0.5 周）

- [x] electron-vite 工程初始化（Vue3 + Pinia + Tailwind + 多入口）
- [x] 主窗口三栏布局空壳、快速输入窗骨架
- [x] 托盘（显隐主窗口 / 退出）+ 单实例锁
- [x] SQLite 接通 + v1 建表迁移机制（见技术设计 §3）
- [x] safeStorage 加解密验证
- [x] electron-builder NSIS 出包验证
- [x] 技术验证清单 8 项全部通过（见技术设计 §7）

### M1 对话 + Key 管理（约 1.5–2 周）

- [x] 供应商 / Key CRUD + safeStorage 加密 + 状态机 + 探测器（手动/周期）
- [x] 网关：故障转移 / 轮询调度、SSE 流式、取消与重试
- [x] 会话 CRUD + 流式渲染（Markdown / 代码高亮）+ 消息操作（停止 / 重生成 / 编辑重发）
- [x] 系统提示词 / 采样参数 / 上下文截断策略
- [x] 会话导出 md / json

### M2 系统级快捷（约 1.5 周）

- [x] 快速输入窗（≤300ms 唤起、Esc 收起、一键转主窗口）
- [x] 托盘右键菜单 + 开机自启（可选）
- [x] 划词：快捷键触发 → 模拟复制 → 结果气泡 → 模板（翻译/总结/解释/自定义）
- [x] 截屏问 AI：框选 → vision 消息 → 主窗口会话留档

### M3 知识库 RAG（约 2 周）

- [x] 知识库 CRUD + 文档导入（pdf/docx/md/txt）+ 后台处理进度
- [x] 参数化切块 + `/embeddings` 向量化 + sqlite-vec 入库
- [x] 对话中 `@知识库` 检索注入 + 引用溯源卡片
- [x] 增量更新 / 重建索引 / 删除连带清理

### M4 Agent 工具调用（约 2 周）

- [x] function calling 循环运行时 + 最大步数限制
- [x] 工具集：读/列/搜文件、网页抓取、写文件、执行命令、剪贴板、打开 URL
- [x] 分级确认 UI（确认卡片 + 会话内记住）+ 授权目录设置
- [x] 执行日志面板 + 停止中断

### M5 打磨（约 1 周）

- [x] 悬浮球（依开放问题 #4 决定去留）
- [x] 全量导出 / 导入备份
- [x] 快捷键自定义完善、主题细节
- [x] 最终 NSIS 安装包 + 简要使用说明

## 3. 开放问题跟进

| # | 问题 | 决策截止 | 状态 |
|---|---|---|---|
| 1 | Embedding 走 API 还是本地 sidecar 兜底 | M3 开工前 | **已落地**：API 与本地 ONNX 双通道（`embed_source` 分流），本地走 onnxruntime-node + faiss-node + BGE 中文模型（技术设计 §9.1） |
| 2 | 中转站 vision 兼容性实测 | M2 开工前 | **已落地**：消息以 `image_url` dataUrl 传给视觉模型（`gateway/index.js`），截屏问 AI 链路可用 |
| 3 | Agent 网页搜索工具选型 | M4 开工前 | **已落地**：`web_search` 工具，Tavily REST 优先 + DuckDuckGo HTML 免 Key 兜底（`agent/web-search.js`） |
| 4 | 悬浮球去留 | M5 开工前 | **已落地·保留**：`entries/floating-ball` 独立入口，随主窗口常驻 |
| 5 | 划词失败兜底（截屏 OCR）是否需要 | M2 开工前 | **未实现**：代码无 OCR 链路，划词失败暂无替补路径 |
| 6 | 同步预留 schema 细节 | 不阻塞、仅记录 | **已落地**：Schema v18 outbox CDC、单写租约、幂等、冲突副本与远程 API；手机 UI E2E 和双设备身份同步验收已通过 |

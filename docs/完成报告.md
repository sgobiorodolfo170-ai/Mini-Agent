### 2.1 E2E 测试（v0.3 新增）

架构：`playwright-core`（不下载浏览器，用 electron.launch 驱动真实应用）+ 本地 OpenAI 兼容 mock 服务（`/v1/models`、`/v1/embeddings`、`/v1/chat/completions` SSE：普通/hang/tool_calls 三模式，429 注入，请求日志）。每个用例独立 userData（`MINIAGENT_USER_DATA`）与 mock 实例，互不污染。运行：`npx vitest run --config vitest.e2e.config.mjs`（fileParallelism 关闭，按文件串行）。

E2E 发现并修复的**生产级缺陷**（单元测试无法暴露）：

1. **preload 全部失效**：4 个 preload 入口共享 chunk 产物含 `require('./chunks/...')`，沙箱 preload 禁止加载相对文件 → `window.api` 整个不存在。修复：合并单入口 preload，`--bridge=xxx` 经 additionalArguments 分发四窗。
2. **Vue reactive Proxy 过不了 contextBridge**：设置页保存供应商等操作在序列化即失败（静默）。修复：store 层统一 `plain()`（toRaw 递归）归一化 IPC 载荷。
3. **Electron 45 `decryptStringAsync` 返回包装对象** `{shouldReEncrypt, result}` 而非字符串 → 所有真实请求鉴权头变成 `Bearer [object Object]`。修复：解密结果归一化。
4. **`plain:` Key 解码 base64 笔误实际仍在**（v0.2 宣称修复未生效）：无 safeStorage 环境下 Key 全部解码错误。修复：`Buffer.from(s, 'base64')`。
5. **streaming 僵尸消息**：流完成瞬间关闭应用，done 落库丢失，重启后该消息永远「生成中…」。修复：启动时把遗留 `streaming` 消息收敛为 `stopped`。
6. **重新生成/编辑重发前端残留旧回复**：软删只落库不刷新渲染层。修复：store 本地同步移除。
7. **done 事件不携带 meta**：流式结束后的知识库引用卡片丢失。修复：done 广播带 meta，前端同步。

M0 技术验证清单 8 项全部落地（见[技术设计 §7](技术设计.md)）：

1. ✅ electron-vite 多入口构建 + NSIS 出包
2. ✅ node:sqlite（DatabaseSync）在 Electron 45 主进程可用（Node 24.22）
3. ✅ Float32 BLOB 向量存取 + JS 余弦 Top-K
4. ✅ safeStorage 异步 API 加解密往返（DPAPI）
5. ✅ SSE 流式客户端（单元测试覆盖，中转站实测需配置 Key 后进行）
6. ✅ desktopCapturer 框选裁剪

8. ✅ 快速窗常驻隐藏、唤起即显

## 3. 功能清单（按里程碑）

**M1 对话 + Key 管理**
- 多会话（新建/重命名/置顶/删除/标题内容搜索）、流式输出、Markdown + 代码高亮 + 代码块复制
- 停止/重新生成/编辑重发、单条消息删除（确认弹窗，v1.1）、会话导出 MD/JSON
- 采样参数 top_p 会话级覆盖（v1.1，与 temperature/max_tokens 同面板）
- 供应商与 Key 管理：DPAPI 加密落盘、401/403→无效、429→冷却、成功恢复的状态机
- 故障转移（默认）/轮询调度，单 Key 失效自动切换不断流；手动/一键探测、事件日志
- 周期自动探测（v1.1，兑现需求 4.2）：按供应商 probe_interval_min 分钟级自动探测全部 Key，≤0 关闭，手动探测后重置计时

**M2 系统级快捷**
- 快速输入窗（默认 `Alt+Space`）：常驻隐藏、Esc 收起、一键转主窗口
- 托盘：左键显隐主窗口、右键菜单、关闭主窗口最小化到托盘
- 划词（默认 `Alt+Q`）：模拟复制 → 剪贴板 diff 取词 → 翻译/总结/解释/自定义模板，结果可复制/转主窗口
- 截屏问 AI（默认 `Alt+S`）：全屏框选（光标所在屏）→ 裁剪 → 作为图片附件进主窗口，vision 模型标记过滤

**M3 知识库 RAG**
- 多知识库管理；pdf/docx/md/txt 导入（pdfjs/mammoth 纯 JS 抽取），后台进度、失败重试、按内容哈希去重
- 标题感知切块（maxLen/overlap 可配）+ 向量化，双通道（v1.1）：
  - 本地嵌入：onnxruntime-node + faiss-node，BGE 中文模型（bge-small-zh-v1.5 / bge-base-zh-v1.5，各提供量化 int8 与非量化 fp32 共四包），设置页一键下载（hf-mirror 源 + 进度广播），全程离线、文档不出本机；
  - 远程嵌入：OpenAI 兼容 `/embeddings`（供应商可配），存量知识库不受影响；
- 检索统一走 faiss `IndexFlatIP`（归一化内积 = 余弦，按库缓存），faiss 不可用自动回退暴力余弦；查询侧自动加 BGE 检索指令前缀
- 对话中勾选知识库 → Top-K 检索注入 → `[n]` 引用溯源卡片（来源/标题路径/相似度）
- 重建索引、删除文档连带清理向量、检索测试面板

**M4 Agent**
- OpenAI function calling 多步循环（默认 15 步上限，可配）
- 21 个内置工具：
  - 文件：list_dir / read_file / search_files（按文件名）/ **grep_files（按内容子串/正则，跳过二进制与大文件）** / write_file / **edit_file（oldText 精确替换，多匹配需扩大上下文或 replaceAll）**
  - 执行：run_command（PowerShell，60s 超时）
  - 联网：web_fetch / **web_search（Tavily 配 Key 优先，DuckDuckGo HTML 端点免 Key 兜底，auto 自动切换）**
  - 计划与记忆：**update_todo（运行内任务清单）** / **save_memory（按小节 upsert 到 userData 的 agent-memory.md，运行开始自动注入系统提示词）**
  - 委派：**spawn_agent（子 Agent 深度固定 1，复用同一套确认/日志管道，工具集不含 spawn_agent）**
  - 浏览器：**browser_navigate / browser_click / browser_type / browser_close（离屏 BrowserWindow 会话，返回页面标题+正文文本）**
  - 扩展：**mcp_list_tools / mcp_call_tool（MCP stdio 客户端，服务器经设置页 agentMcpServers JSON 配置，模型只能调已配置服务器）**
  - 系统：clipboard_read / clipboard_write / open_url
- 分级确认：只读自动放行（含 grep_files/web_search/update_todo/save_memory/browser_navigate/browser_close/mcp_list_tools）；副作用（写文件/编辑文件/执行命令/剪贴板/打开 URL/spawn_agent/browser_click/browser_type/mcp_call_tool）确认卡片 + 会话内记住；破坏性命令（format/diskpart/递归强删等）始终确认
- 授权目录白名单（默认不授权任何目录）、命令 60s 超时与输出截断
- 执行日志全量落库（agent_tool_calls），Agent 页可回放明细、随时停止
- 设置页 Agent 区新增：联网搜索通道（auto/tavily/ddg）、Tavily Key、MCP 服务器 JSON 配置

**M5 打磨**
- 悬浮球（可拖拽、点击唤起快速窗、设置可关）
- 全量备份导出/导入（JSON 单文件，可选包含 API Key 明文）
- 快捷键自定义（注册冲突上报）、深色/浅色/跟随系统主题、开机自启开关

## 4. 与设计的偏差（均已在[技术设计 v0.2](技术设计.md) 留痕）

| 设计 | 实际落地 | 理由 |
|---|---|---|
| better-sqlite3 + sqlite-vec | **node:sqlite（内置）+ JS 余弦检索** | 零原生模块：规避 ABI 重建与 GitHub 下载超时风险；个人规模（万级块）暴力余弦毫秒级 |
| safeStorage 同步 API | **异步 API（Electron 45 推荐）** | 45 已弃用同步版，异步优先、同步兜底 |
| 划词 SendInput 原生模块 | **PowerShell SendKeys** | 零依赖，延迟约 400ms 可接受；失败兜底截屏问 AI |
| 划词独立气泡窗 | **复用快速输入窗（划词模式）** | 减少一个窗口类型，体验一致 |

## 5. 已知限制（v1.0）

- 截屏问 AI 仅支持光标所在显示器；多屏全选为后续增强
- 划词在管理员权限/部分全屏窗口可能取不到剪贴板变化（提示改用截屏）
- 流式过程中途失败不自动换 Key 重试（仅请求建立阶段换）；断流可直接重新生成
- 安装包未签名（自用工具；SmartScreen 首次运行可能提示）
- pdf 扫描件（图片型）无 OCR，提取不到文本会标记 error
- Agent 的 web_fetch 为正文抽取的简化实现，复杂页面效果有限
- web_search 的 DuckDuckGo 兜底依赖其 HTML 端点页面结构，改版时会解析失败（此时报错而非返回空结果；配置 Tavily Key 可规避）
- browser_* 为轻量方案：仅支持文本级交互（点击/填表），无验证码/截屏识别能力；会话随运行结束自动关闭
- **本地嵌入模型包需联网下载一次**（hf-mirror 源，量化 small 约 22MB / 非量化 base 约 388MB），下载后完全离线；量化版精度较非量化版略降（个人场景可接受）
- **faiss-node 预编译产物**：中国网络环境 `npm install` 时 prebuild-install 直连 GitHub release 易超时，需经镜像下载对应 NAPI 版资产放入 `node_modules/faiss-node/build/Release/`（本仓库开发机已就位；CI 直连正常）；应用安装包内已打包该产物，最终用户无感
- mcp_call_tool 每次调用都起停一次服务器进程（无长驻会话），高频调用场景启动开销明显
- spawn_agent 子 Agent 与主 Agent 共享确认队列与会话内「记住」授权，步数上限取 min(10, 配置值)

## 6. 首次使用

1. 双击 `dist-app/miniagent Setup 1.0.0.exe` 安装并启动（桌面有快捷方式，托盘常驻）；
2. 「设置 → 模型服务」添加供应商：填 Base URL（如中转站 `https://xxx/v1`）+ API Key（自动 DPAPI 加密），可「拉取模型」或手动添加模型 ID，需要看图的模型勾选 👁；
3. 设默认供应商/模型；点「一键探测」确认 Key 可用；
4. `Alt+Space` 唤起快速窗试一句话；主窗口建会话开聊；
5. 需要知识库：「知识库」页建库（选 Embedding 供应商+模型）→ 导入文档 → 对话时勾选知识库；
6. 需要动手能力：会话输入框开「Agent 模式」+「设置 → Agent」授权目录后下发任务，逐步确认执行。

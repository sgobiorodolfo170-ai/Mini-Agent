## 1. 项目概述

Mini Agent 是一个**跑在 Windows 桌面的个人 AI 助理**：

- 主窗口多会话对话（日常主力形态）；
- 托盘常驻 + 全局快捷键随时唤起快速输入窗；
- 划词、截屏即问，不离开当前应用；
- 本地知识库问答（RAG），回答带引用溯源；
- Agent 工具调用：能读写文件、执行命令，自主拆解完成任务（分级确认）。

**定位：自用工具**。功能优先，不追求商业化打磨；不做账号体系、不做遥测。

## 2. 目标与非目标

### 目标

1. 一个窗口覆盖「问答—查资料—干活」三类需求，数据全部本地；
2. OpenAI 兼容协议统一接入，多 Key 管理与故障自动切换，单点 Key 失效不中断使用；
3. 系统级快捷入口让「问一句」的成本低于 3 秒（快捷键 → 输入 → Esc 收起）；
4. 知识库问答可溯源，引用可跳回原文；
5. Agent 操作本地系统时风险可控（分级确认 + 执行日志）。

### 非目标（本期不做）

- macOS / Linux / 移动端；
- 账号、登录、云端同步实现（仅做数据结构预留）；
- 多人协作、分享链接；
- 自动更新（自用可手动重装，v2 再评估）；
- 商业化、License 校验。

## 3. 用户与核心场景

| # | 场景 | 用到的能力 |
|---|---|---|
| S1 | 顺手问一句「这段正则是干嘛的」，按快捷键唤起小窗，问完收起 | 快捷唤起 |
| S2 | 长对话调试一个项目，开着主窗口连续追问、切换模型对比回答 | 对话助手 |
| S3 | 正在用的 Key 突然 429/失效，应用自动切到下一把可用 Key，无感继续 | Key 管理 |
| S4 | 网页里选中一段英文，一键翻译/总结，结果贴回原处 | 划词 |
| S5 | 截一张报错弹窗或 UI 图，直接问「这个错怎么解」 | 截屏问 AI（vision） |
| S6 | 导入一批项目文档，提问后回答带出处，点引用跳回原文 | 知识库 RAG |

| S8 | 不想开窗口，点屏幕边缘悬浮球直接提问 | 悬浮球（后期） |

## 4. 功能需求

### 4.1 对话助手（M1）

- 多会话管理：新建、重命名、置顶、删除、按标题/内容搜索；
- 流式输出；Markdown 渲染 + 代码高亮 + 代码块复制；
- 消息操作：停止生成、重新生成、编辑后重发、删除、复制；
- 上下文管理：会话超长时按策略截断（保留系统提示词 + 最近 N 轮，可配）；
- 系统提示词：全局默认 + 会话级覆盖；
- 采样参数：temperature / top_p / max_tokens，默认值 + 会话级覆盖；
- 导出：单会话导出 Markdown / JSON。

### 4.2 模型接入与 Key 管理（M1）

> 复用 apikey测试工具 与中转站的成熟语义。

- 供应商（Provider）= 名称 + Base URL + Key 列表 + 模型列表，全部 OpenAI 兼容协议；
- 每把 Key 独立状态机：`未知 → 可用 / 无效(401/403) / 冷却中(429)`，成功请求即恢复；
- 测活探测：最小化请求（`/chat/completions` + `max_tokens=1`），手动 + 周期自动（间隔可配）；
- 请求调度策略：**故障转移**（默认：当前 Key 报错自动换下一把，可配重试次数）与**轮询**二选一；
- 模型条目可标记「支持视觉」，供截屏/图片消息选择模型时过滤；
- Key 落盘用 Windows DPAPI 加密（Electron safeStorage），界面不明文回显。

### 4.3 系统级快捷（M2）

- **快速输入窗**：全局快捷键（默认 `Alt+Space`，可改）唤起无边框置顶小窗；输入 → 回答（流式）→ `Esc` 收起；可一键「转入主窗口会话」继续深聊；
- **托盘**：左键显隐主窗口；右键菜单（打开主窗口 / 快速输入 / 设置 / 退出）；关闭主窗口默认最小化到托盘；
- **划词**：选中文字后按快捷键（或弹出悬浮小按钮）→ 翻译 / 总结 / 解释 / 自定义 Prompt 模板，结果气泡展示，可复制、可发送到主窗口；
- **截屏问 AI**：快捷键 → 框选区域 → 可附一句话 → 发给视觉模型；历史截屏问答可在主窗口查看。

### 4.4 知识库 RAG（M3）

- 知识库：可建多个库（如「工作文档」「某项目资料」），分别管理；
- 导入格式：pdf / docx / md / txt（epub 视进度）；大文件分块后台处理，带进度与失败重试；
- 切块 + 向量化：Embedding 走 OpenAI 兼容 `/embeddings`（供应商可配），并可选用本地 ONNX 模型离线嵌入（BGE 中文，onnxruntime-node + faiss-node，详见技术设计 §9.1）；
- 向量存储：SQLite 存分块文本与向量，检索用 faiss-node `IndexFlatIP` 内存索引（加载失败回退 JS 余弦）；
- 使用方式：对话中 `@知识库` 选择本次检索的库；检索 Top-K 注入上下文；
- 引用溯源：回答标注 `[1][2]` 引用块，点开展示原文片段与所属文档，可跳转定位；
- 维护：增量更新（文件变更重导入）、手动重建索引、删除文档连带清理向量。

### 4.5 Agent 工具调用（M4）

- 协议：OpenAI 兼容 function calling（`tools` / `tool_calls`），多步循环（工具结果回传继续推理），最大步数可配（默认 15 步）；
- 内置工具第一版清单：

| 工具 | 风险级 | 行为 |
|---|---|---|
| 读文件 / 列目录 / 搜索文件（限定授权目录） | 只读 | 自动执行 |
| 网页抓取（给 URL 返回正文） | 只读 | 自动执行 |
| 写 / 改文件（限定授权目录） | 副作用 | 确认 |
| 执行 PowerShell 命令 | 副作用 | 确认 |
| 剪贴板读 / 写 | 副作用 | 确认 |
| 打开 URL | 副作用 | 确认 |
| 删除文件、其他高风险 | 破坏性 | 始终确认且不可「本次不再问」 |

- **分级确认**：副作用工具弹确认卡片（展示将要执行的完整命令 / 写入路径与内容摘要），可勾选「本会话内同类操作不再确认」；破坏性操作始终确认；
- 授权目录：Agent 只能在用户显式授权的目录内读写文件，默认不授权任何目录；
- 执行日志面板：每步工具调用、参数、结果、耗时、是否人工确认，全程可回放；随时「停止」中断当前任务。

### 4.5.1 Agent 集群（2026-11-26 增量）

- 单机有界集群，`cluster` 是所有多 Agent 编排工具的总闸；关闭时只允许单 Agent 执行。
- 自动编排流程：模型拆解 → Draft Plan → 用户预览并确认 → 原子创建子 Run 与依赖图 → 有界并发执行 → 父任务汇总。
- 子 Agent 默认继承父任务有效权限，受授权目录、Mandate 与应用策略约束；命令和破坏性操作始终逐次审批。
- 固定上限：全局 4 个执行槽、每个父 Run 2 个直属子任务、任务图 12 节点 / 深度 3 / 并发 4、委派深度 3。
- 可写子任务在 Git 项目中自动使用 Worktree；共享目录通过写租约串行化，Worktree 失败不静默降级。
- 桌面与手机端展示计划、父子关系、任务图、状态、日志、结果和工作区；手机操作继续受角色权限与 CSRF 约束。

### 4.6 交互形态（跨模块）

- **主窗口**：三栏布局（会话列表 / 对话区 / 会话详情），深浅色主题跟随系统 + 手动切换；
- **快速输入窗**：见 4.3；
- **悬浮球**（M5，可裁剪）：屏幕边缘半透明小球，可拖拽、可隐藏，点击展开迷你面板；
- **设置中心**：供应商与 Key、快捷键自定义、Agent 授权目录、数据目录、开机自启（可选）、主题。

### 4.7 数据与存储

- 全部数据存本地 SQLite（会话、消息、配置、Key 元数据、向量、执行日志），数据目录可自定义；
- Key 密文用 DPAPI 加密存储；
- **预留同步**：核心表带 `uuid` / `updated_at` / 软删除标记，为将来端到端同步/备份留结构，本期不实现；
- 全量导出 / 导入（JSON + 附件打包），作为手工备份手段。

## 5. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 冷启动 ≤ 2s；快速输入窗唤起 ≤ 300ms；流式首 token 响应及时；内存常态目标 < 300MB（Electron 下需刻意控制） |
| 安全 | Key DPAPI 加密；Agent 分级确认；网络请求仅发往用户配置的模型 API，无遥测 |
| 隐私 | 对话、知识库、日志全部本地；上传内容仅限用户主动发送的对话/文档 |
| 可靠性 | 单实例锁；输入草稿防丢（崩溃/误关恢复）；流式中断可重试 |
| 兼容 | Win10+ / Win11；自带 Chromium 运行时，无系统 WebView 依赖 |

## 6. 技术选型与架构

### 选型

| 层 | 选择 | 说明 |
|---|---|---|
| 壳 | Electron（稳定大版本，主进程 Node.js） | 系统级 API 内置齐全（Tray / globalShortcut / desktopCapturer / clipboard），全程 JS/TS |
| 前端 | Vue 3 + Vite + Pinia + Tailwind | 延续现有技术经验（与 apikey测试工具 同栈） |
| 进程通信 | ipcMain / ipcRenderer + contextBridge（preload 隔离） | 渲染层沙箱化，流式输出由主进程逐段推送 |
| HTTP | 主进程 Node fetch（undici）直连模型端点 | 绕开渲染层 CORS；API Key 不进渲染进程 |
| 存储 | SQLite（Node 内置 node:sqlite，主进程）+ JS 余弦向量检索 | 零原生模块，规避 ABI 与下载风险 |
| 托盘/快捷键 | Electron Tray + globalShortcut（内置） | — |
| 快捷窗/悬浮球 | BrowserWindow：frameless + alwaysOnTop + skipTaskbar（悬浮球加 transparent） | 常驻隐藏、唤起即显 |
| 划词 | 全局快捷键触发 → 模拟 Ctrl+C → 读剪贴板 | UIA 取选区作备选；失败兜底截屏 |
| 截屏 | desktopCapturer 取屏 + 自绘框选层 | 产出 base64 dataURL 发视觉模型 |
| Key 加密 | Electron safeStorage（Windows 下即 DPAPI） | 界面不明文回显 |
| 打包 | electron-builder（NSIS 安装包） | 无原生模块，无需 ABI 重建 |

### 架构（文字版）

```
┌─ Renderer（Vue 3，沙箱化）───────────────────
│ 主窗口 / 快速输入窗 / 悬浮球 / 设置中心
│ 不直接访问 Node 与网络，仅经 preload 桥
└──────────── contextBridge + ipcRenderer ─────
┌─ Main（Node.js 主进程）──────────────────────
│ 模型网关(多Key调度·流式·探测)
│ RAG 索引器(切块·Embedding·向量检索)
│ Agent 运行时(工具循环·分级确认·日志)
│ 系统服务(托盘·全局快捷键·划词·截屏·剪贴板)
│ 存储(SQLite + safeStorage/DPAPI)
└──────────────────────────────────────────────
        │ HTTP(SSE)
   用户配置的 OpenAI 兼容端点（中转/官方）
```

## 8. 开放问题（不阻塞 M0/M1，按期前定稿）

1. **Embedding 方案**：默认走中转 `/embeddings`；是否需要本地 sidecar 兜底（断网/隐私敏感文档）？→ M3 前定；
2. **视觉模型兼容性**：确认常用中转对 `image_url`(base64) 的支持情况 → M2 前用现有中转实测；
3. **网页搜索工具选型**（Agent 可选工具）：Tavily / SearXNG / 中转站搜索接口 → M4 前定；
4. **悬浮球去留**：若 M5 前感觉快捷窗已覆盖场景，悬浮球可裁剪；
5. **划词兼容边界**：管理员权限/全屏应用窗口可能取不到选区，是否接受「截屏 OCR 兜底」方案；
6. **同步预留的表结构细节**（冲突策略、附件同步）→ 仅记录，不实现。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| Electron 包体与内存偏高（~85MB+ / 300MB 级） | 自用工具可接受；窗口惰性创建与启动项精简控制内存 |
| 中转站流式/SSE 兼容性差异（超时、断流、假流式） | 网关层统一重试与降级；沿用 apikey测试工具 的探测语义（401/403/429） |
| 原生模块（onnxruntime-node、faiss-node）与 Electron ABI 匹配 | 两者均为 NAPI 二进制，Node/Electron 通用、无需按 ABI 重建；已进 `dependencies` 并由 `asarUnpack` 解包，M0 技术验证清单覆盖加载验证 |
| RAG 效果依赖切块与检索策略 | M3 先做可配置切块（按标题/长度/重叠），留重建索引能力便于调参 |
| Agent 误操作本地系统 | 授权目录白名单 + 分级确认 + 执行日志 + 最大步数限制 |

# 内置浏览器研发契约

更新日期：2026-11-24

## 1. 首版边界

- 产品形态：主窗口内可见浏览器，支持多标签、人工操作和 Agent 操作。
- 技术底座：复用 Electron Chromium，以 `WebContentsView` 嵌入主窗口；不引入产品级 Playwright 运行时。
- 用户标签：使用持久化分区保存登录态。
- Agent 标签：按 Run 使用非持久化临时分区，不继承用户 Cookie；Run 结束立即关闭。
- Agent 只能操作自己的临时标签。用户可在工具栏人工接管；接管后 Agent 调用返回 `BROWSER_TAKEN_OVER`。
- 首版不支持任意 JavaScript 执行工具、自动验证码绕过、无确认支付、手机远程浏览器控制和 Agent 自主文件上传。

## 2. 信任边界

- 浏览器页面没有 Node、preload 和宿主 IPC 能力。
- 渲染层只能通过主进程窄 IPC 控制浏览器，不能直接持有 `WebContents`。
- 网页正文、标题和元素快照属于不可信数据，不作为宿主指令执行。
- 用户标签与 Agent 标签存储隔离；Agent 标签关闭后清理会话数据。
- 导航、点击、输入和关闭均按副作用工具审批；密码字段不进入审批、事件和工具审计日志。

## 3. 状态模型

```js
{
  enabled: true,
  activeTabId: 'tab-xxx',
  attachedTabId: null,
  tabs: [{
    id: 'tab-xxx',
    kind: 'user' | 'agent',
    runId: null,
    title: '页面标题',
    url: 'https://example.com/',
    loading: false,
    error: null,
    owner: 'user' | 'agent',
    createdAt: 1763980800000,
    bounds: { x: 80, y: 120, width: 900, height: 600 }
  }],
  policy: {
    allowPrivateNetwork: false,
    maxTabs: 6
  }
}
```

- `kind=user`：持久化登录分区，只能人工操作。
- `kind=agent`：Run 临时分区，初始 `owner=agent`；人工接管后 `owner=user`。
- `attachedTabId` 非空时，当前标签的 `WebContentsView` 嵌入浏览器页面区域。
- 切换页面或离开浏览器页时，视图必须分离或隐藏，不能覆盖标题栏、导航和其他对话框。

## 4. IPC 契约

所有浏览器 IPC 仅允许主窗口调用。

| 通道 | 参数 | 返回 |
|---|---|---|
| `browser:state` | 无 | 完整状态 |
| `browser:setEnabled` | `{ enabled }` | 完整状态 |
| `browser:open` | `{ url?, kind? }` | 标签摘要 |
| `browser:navigate` | `{ tabId, url }` | 标签摘要 |
| `browser:activate` | `{ tabId }` | 完整状态 |
| `browser:close` | `{ tabId }` | 完整状态 |
| `browser:command` | `{ tabId, command }` | 标签摘要 |
| `browser:attach` | `{ tabId, bounds }` | 完整状态 |
| `browser:detach` | 无 | 完整状态 |
| `browser:takeover` | `{ tabId }` | 标签摘要 |
| `browser:release` | `{ tabId }` | 标签摘要 |
| `browser:screenshot` | `{ tabId }` | `{ path, width, height }` |
| `browser:clearData` | 无 | `true` |

`command` 取值：`back`、`forward`、`reload`、`stop`。

事件统一为 `browser:event`：

```js
{
  type: 'state' | 'blocked' | 'download',
  state: { /* 完整状态 */ },
  tabId: 'tab-xxx',
  reason: '可选',
  download: { /* 可选 */ }
}
```

## 5. Agent 工具契约

- `browser_navigate`：`{ url, tabId? }`，无 `tabId` 时使用当前 Run 的临时标签。
- `browser_snapshot`：`{ tabId?, maxChars? }`，返回不可信页面快照和可交互元素 `ref`。
- `browser_click`：`{ tabId?, ref?, selector? }`，`ref` 与 `selector` 二选一。
- `browser_type`：`{ tabId?, ref?, selector?, text, submit? }`，定位方式二选一。
- `browser_wait`：`{ tabId?, ref?, selector?, ms? }`。
- `browser_scroll`：`{ tabId?, x?, y? }`。
- `browser_screenshot`：`{ tabId? }`。
- `browser_tabs`：无参数，仅返回当前 Run 可访问标签。
- `browser_close`：`{ tabId? }`，关闭当前 Run 的临时标签。

旧四工具调用保持兼容；未传 `tabId` 时复用当前 Run 标签。浏览器副作用在中断恢复时不自动重放。

## 6. 错误码

| 错误码 | 含义 |
|---|---|
| `BROWSER_DISABLED` | 内置浏览器已停用 |
| `BROWSER_TAB_NOT_FOUND` | 标签不存在或已关闭 |
| `BROWSER_URL_BLOCKED` | URL 协议、地址或域名策略不允许 |
| `BROWSER_NAVIGATION_TIMEOUT` | 页面加载超时 |
| `BROWSER_TAKEN_OVER` | 用户已人工接管，Agent 不可继续操作 |
| `BROWSER_RUN_MISMATCH` | Agent 尝试访问其他 Run 的标签 |
| `BROWSER_TAB_LIMIT` | 超过标签上限 |
| `BROWSER_TARGET_NOT_FOUND` | 点击、输入或等待的目标元素不存在 |
| `BROWSER_VIEW_UNAVAILABLE` | 当前环境无法创建浏览器视图 |

## 7. 安全与资源约束

- 仅允许 `http:`、`https:` 和内部 `about:blank`。
- 默认拒绝本地回环、私网、链路本地和保留地址；可在设置中显式开放内网访问。
- 用户点击、页面跳转和重定向在主进程重新校验。
- Agent 标签拒绝弹窗、权限请求和下载；用户标签弹窗转为同分区标签。
- 下载文件写入专用下载目录，文件名清洗并避免覆盖。
- 默认最多 6 个标签；导航超时 30 秒；快照最多 20,000 字符。
- 功能停用、应用退出和 Run 结束时必须销毁对应视图并释放事件监听。

miniagent 架构总览

三进程 Electron 架构：渲染层只做 UI，模型网关、Agent 运行时、RAG 与系统集成全部收敛在主进程，SQLite 单文件落盘。

PROCESS · WINDOWS

进程与窗口

  • 主窗口 · 快速输入窗（Alt+Space，预创建 ≤300ms 唤起）· 悬浮球 · 框选截屏层（Alt+S）
  • contextIsolation + sandbox，preload 按窗注入最小 API 面
  • 关闭主窗隐藏至托盘，托盘「退出」才真退出

DATA · KEYS

数据与密钥

  • node:sqlite（Electron 45 内置 Node 24.22）11 张业务表，软删字段预留同步
  • Key 经 safeStorage（Windows DPAPI）加密落库，渲染层只见尾 4 位
  • 向量 Float32 BLOB + 纯 JS 余弦 Top-K，零原生模块
